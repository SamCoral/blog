# TechPulse Blog

A simple static blog and admin dashboard demo built with HTML, CSS, and JavaScript.

## Features

- Responsive public blog homepage
- Article listing and detail pages
- Admin dashboard for managing posts
- LocalStorage-powered content and theme persistence
- Dark/light theme toggle

## Run locally

From the project root:

```bash
npm start
```

Then open http://localhost:8000. You can override the port with:

```bash
PORT=3000 npm start
```

## Notes

This project is a frontend-only demonstration and does not use a backend service.
